# Générer un code voucher

## Quand l’utiliser
Un client a besoin de générer un code voucher dans le portail agence.

## Étapes
1. Dans le menu du portail, ouvrez **Gestion des vouchers** et sélectionnez l’onglet **Générer un code voucher**.
2. Remplissez l’étape **Informations de l’expéditeur** avec les renseignements fournis par le client, en suivant les indications du parcours.
3. Sélectionnez le compte à débiter, saisissez le montant du voucher et un motif, puis cliquez sur **Procéder**.
4. Vérifiez le récapitulatif et les frais. Si **Inventaire des dénominations de cash** s’affiche, comptez et saisissez le nombre de chaque billet et pièce reçus. Comparez le total calculé au montant cible, saisissez le montant collecté, puis cliquez sur **Confirmer et déposer**.
5. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé.
6. Lorsque le résultat confirme la réussite et affiche le code voucher, copiez-le exactement et remettez-le au client. Indiquez-lui de l’utiliser avant son expiration.

## Erreurs fréquentes
- Vous avez ouvert l’annulation alors qu’il faut générer un code, ou l’inverse : arrêtez-vous et ouvrez le guide correspondant avant de poursuivre.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
