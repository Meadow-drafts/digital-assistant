# Recharge de crédit téléphonique

## Quand l’utiliser
Un client a besoin d’aide pour une recharge de crédit téléphonique.

## Étapes
1. Dans le menu du portail, ouvrez **Paiements** et sélectionnez **Recharge de crédit**.
2. Sélectionnez le pays et l’opérateur mobile, puis remplissez l’étape **Informations de l’expéditeur** comme indiqué.
3. Sélectionnez le compte à débiter. Saisissez et vérifiez le numéro de téléphone du client, puis indiquez le montant de la recharge.
4. Cliquez sur **Proceed** et vérifiez le numéro, l’opérateur, le montant et les frais affichés.
5. Si **Inventaire des dénominations de cash** s’affiche, saisissez le nombre de billets et de pièces reçus par dénomination, vérifiez le total par rapport au montant cible, saisissez le montant collecté, puis cliquez sur **Confirmer et déposer**.
6. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé. Attendez le résultat avant de tenter une autre recharge.

## Erreurs fréquentes
- Le client souhaite un forfait Internet et non du crédit téléphonique : consultez Recharge Internet.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
