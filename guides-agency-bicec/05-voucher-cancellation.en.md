# Cancel Voucher Code

## When to use
A customer asks about cancelling an existing voucher code.

## Steps
1. Open **Voucher Management** from the portal menu and select the **Cancel Voucher Code** tab.
2. Enter the existing voucher code and click **Proceed**.
3. Check that the voucher details displayed by the portal identify the code the customer wants cancelled. Stop if the code or details do not match.
4. Enter the transaction PIN in the portal and provide the OTP there if requested.
5. Wait for the cancellation result. A cancelled voucher can no longer be redeemed. If the result is pending or unclear, check its status or contact authorized agency support before trying again.

## Common errors
- The request is to create a code, not cancel one: switch to Generate Voucher Code. If the code or requested action is unclear, pause and contact support.
- A field is missing, disabled, or rejected: read the portal’s message and check the relevant information. Do not invent a value; ask authorized agency support if the message does not explain what to do.
- The result is unclear or has not appeared: do not repeat the action. Check the status in the portal or ask authorized agency support.

This guide does not confirm fees, limits, eligibility, corridors, or exceptions. Check an approved bank source for those details.

The assistant never asks for your PIN, OTP, or another authentication secret. Do not share one in chat.

## Talk to a human if
The portal does not explain what to do next, a status remains unclear, or the customer needs help beyond these steps. Use the Human-agent option and review and edit the case summary before handoff.
