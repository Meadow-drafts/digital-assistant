# Voucher Paiement Marchand

## Quand l’utiliser
Un client a besoin d’aide pour un voucher de paiement marchand.

## Étapes
1. Dans le menu du portail, ouvrez **Gestion des vouchers**, puis **Voucher Paiement Marchand**.
2. Choisissez **Générer un code voucher** pour créer un voucher de retrait marchand ou **Annuler un code voucher** pour annuler un code existant.
3. Pour créer un code, remplissez l’étape **Informations de l’expéditeur**. Sélectionnez le compte à débiter, saisissez le montant et le motif, puis renseignez les informations du bénéficiaire demandées dans le formulaire. Cliquez sur **Procéder**.
4. Vérifiez le récapitulatif et les frais. Si **Inventaire des dénominations de cash** s’affiche, saisissez le nombre de billets et de pièces reçus par dénomination, comparez le total au montant cible, saisissez le montant collecté, puis cliquez sur **Confirmer et déposer**.
5. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé. Copiez le code voucher affiché dans le résultat de réussite et remettez-le au bénéficiaire prévu.
6. Pour annuler un code, saisissez le code voucher existant dans l’onglet d’annulation, cliquez sur **Procéder**, vérifiez les détails affichés, puis saisissez le PIN et tout OTP demandé. Attendez le résultat de l’annulation.

## Erreurs fréquentes
- Le client parle de générer ou d’annuler un code voucher et non d’un paiement marchand : ouvrez le guide voucher correspondant.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
