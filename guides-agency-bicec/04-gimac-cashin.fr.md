# Cash-in GIMAC

## Quand l’utiliser
Le client a besoin d’aide pour le workflow de cash-in GIMAC.

## Étapes
1. Dans le menu du portail, ouvrez **Cashin - Cashout GIMAC**, puis sélectionnez l’onglet **Dépôt en espèces**.
2. Sélectionnez le pays de destination, puis choisissez **Compte** ou **Wallet** dans **Type de transfert**.
3. Sélectionnez l’opérateur de destination et remplissez l’étape **Informations de l’expéditeur** avec les renseignements fournis par l’expéditeur. Suivez les indications du parcours pour accéder au formulaire de transaction.
4. Sélectionnez le compte à débiter. Saisissez le compte/IBAN ou l’identifiant wallet de destination, le montant du cash-in et un motif (au moins trois mots).
5. Cliquez sur **Dépôt en espèces**. Vérifiez dans le récapitulatif le pays, l’opérateur, la destination, le montant et les frais.
6. Si **Inventaire des dénominations de cash** s’affiche, saisissez le nombre de billets et de pièces reçus par dénomination. Le portail calcule le total à partir des quantités et valeurs. Comparez-le au montant cible, saisissez le montant collecté, puis cliquez sur **Confirmer et déposer**.
7. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé. Attendez le résultat avant de commencer une autre opération.

## Erreurs fréquentes
- La page affiche le workflow privé : arrêtez-vous et choisissez GIMAC. Ne poursuivez pas dans le mauvais workflow.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
