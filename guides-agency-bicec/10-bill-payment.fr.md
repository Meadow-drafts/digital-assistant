# Paiement de facture

## Quand l’utiliser
Un client a besoin d’aide pour payer une facture dans le portail agence.

## Étapes
1. Dans le menu du portail, ouvrez **Paiements** et sélectionnez **Paiement de facture**.
2. Sélectionnez le pays et le facturier/opérateur, puis remplissez l’étape **Informations de l’expéditeur** comme indiqué.
3. Sélectionnez le compte à débiter. Choisissez **Bill Number** ou **Contract Number**, saisissez la référence correspondante, puis cliquez sur **Proceed**.
4. Dans la consultation des factures, vérifiez la liste. Cochez chaque facture impayée que le client souhaite régler, puis cliquez sur **Validate**.
5. Vérifiez les références sélectionnées et le total. Si **Inventaire des dénominations de cash** s’affiche, saisissez le nombre de billets et de pièces reçus par dénomination, comparez le total au montant cible, saisissez le montant collecté, puis cliquez sur **Confirmer et déposer**.
6. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé. Attendez le résultat du paiement ; ne soumettez pas à nouveau la même facture si son statut est incertain.

## Erreurs fréquentes
- Le client demande une recharge de crédit ou Internet et non un paiement de facture : consultez le guide correspondant.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
