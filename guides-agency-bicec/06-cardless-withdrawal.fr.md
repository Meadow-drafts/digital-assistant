# Retrait sans carte

## Quand l’utiliser
Un client a besoin d’aide pour le workflow Retrait sans carte.

## Étapes
1. Dans le menu du portail, ouvrez **Gestion des vouchers**, puis sélectionnez **Retrait sans carte**.
2. Sélectionnez l’onglet **Retrait sans carte** pour créer une demande de retrait ou **Annuler la demande** pour annuler une demande existante.
3. Pour un retrait, sélectionnez le compte à débiter, saisissez le numéro de téléphone du bénéficiaire et le montant (le formulaire exige un montant multiple de 5 000), puis remplissez les renseignements de l’expéditeur demandés. Pour une annulation, saisissez plutôt le code de la demande.
4. Cliquez sur **Procéder** et vérifiez les détails affichés par le portail. Si l’inventaire des dénominations s’affiche pour le retrait, saisissez le nombre de billets et de pièces par dénomination, comparez le total au montant cible, saisissez le montant collecté, puis confirmez.
5. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé. Attendez le résultat ; pour une annulation, vérifiez qu’il concerne la demande prévue.

## Erreurs fréquentes
- Le client parle d’un workflow de cash-out et non d’un retrait sans carte : demandez quel type de cash-out il souhaite, puis ouvrez le guide correspondant.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
