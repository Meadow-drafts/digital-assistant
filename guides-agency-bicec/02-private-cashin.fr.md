# Cash-in privé (interne)

## Quand l’utiliser
Le client a besoin d’aide pour le workflow de cash-in privé/interne.

## Étapes
1. Dans le menu du portail, ouvrez **Cashin - Cashout Interne**, puis sélectionnez l’onglet **Dépôt en espèces**.
2. Dans **Type de transfert**, sélectionnez **Compte** ou **Wallet** selon la destination du client.
3. Remplissez l’étape **Informations de l’expéditeur** avec les renseignements fournis par l’expéditeur. Suivez les indications du parcours pour accéder au formulaire de transaction.
4. Sélectionnez le compte à débiter. Saisissez le numéro du compte de destination ou l’identifiant wallet, le montant du cash-in et un motif (au moins trois mots).
5. Cliquez sur **Dépôt en espèces**. Vérifiez dans le récapitulatif la destination, le montant et les frais.
6. Si **Inventaire des dénominations de cash** s’affiche, comptez les billets et les pièces reçus. Saisissez le nombre de chaque dénomination ; le portail multiplie chaque quantité par sa valeur et calcule le total. Vérifiez que ce total correspond au montant cible, saisissez le montant collecté, puis cliquez sur **Confirmer et déposer**.
7. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé. Attendez le résultat avant de commencer une autre opération.

## Erreurs fréquentes
- La page affiche le workflow GIMAC : arrêtez-vous et choisissez le workflow privé. Ne poursuivez pas dans le mauvais workflow.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
