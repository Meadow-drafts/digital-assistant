# Envoi sortant

## Quand l’utiliser
Un client demande des informations sur l’envoi d’un transfert.

## Étapes
1. Dans le menu du portail, ouvrez **Remittance** et sélectionnez l’onglet **Outgoing Remittance**.
2. Sélectionnez le pays et l’opérateur de destination, puis choisissez si le bénéficiaire recevra les fonds sur un **Account**, un **Wallet** ou une **Card**.
3. Sélectionnez le compte à débiter et saisissez le numéro de compte/carte ou l’identifiant wallet correspondant.
4. Saisissez le montant et le motif, puis renseignez les nom et prénom du bénéficiaire, le type et le numéro de pièce d’identité, l’adresse, la ville, le pays et le numéro de téléphone. Remplissez l’étape **Sender Information** avec les renseignements fournis par l’expéditeur.
5. Cliquez sur **Proceed** et vérifiez le bénéficiaire, la destination, le montant et les frais affichés par le portail.
6. Si **Cash Denomination Tally** s’affiche, saisissez le nombre de billets et de pièces reçus par dénomination, vérifiez le total par rapport au montant cible, saisissez le montant collecté, puis cliquez sur **Confirm and Deposit**.
7. Saisissez le code PIN de transaction dans le portail et l’OTP dans le portail s’il est demandé. Attendez le résultat avant d’effectuer une autre remise.

## Erreurs fréquentes
- Le client veut recevoir de l’argent et non en envoyer : consultez Réception de transfert avant de poursuivre.
- Un champ est manquant, désactivé ou refusé : lisez le message du portail et vérifiez l’information concernée. N’inventez pas de valeur ; si le message n’explique pas quoi faire, contactez le support agence habilité.
- Le résultat n’est pas clair ou ne s’affiche pas : ne répétez pas l’action. Vérifiez son statut dans le portail ou demandez au support agence habilité.

Ce guide ne précise pas les frais, plafonds, critères d’éligibilité, corridors ou exceptions. Consultez une source bancaire approuvée pour ces informations.

L’assistant ne demande jamais votre PIN, OTP ou autre secret d’authentification. Ne le partagez pas dans le chat.

## Parlez à un agent si
Le portail n’explique pas la prochaine étape, le statut reste incertain ou le client a besoin d’aide au-delà de ce guide. Utilisez l’option Agent humain, puis relisez et modifiez le résumé du dossier avant le transfert.
