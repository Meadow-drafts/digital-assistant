# Obtenir un relevé de compte

## Quand l'utiliser
Vous avez besoin d'un relevé pour un compte sur une période, en PDF ou par e-mail.

## Étapes
1. Ouvrez **Historique**, puis **Historique Compte**. Si vous ne le voyez pas, vous n'êtes pas la connect principale (voir Paramètres > Gérer les connects).
2. Sélectionnez le compte, puis ouvrez l'onglet **Relevé de compte**.
3. Choisissez la période : **30 derniers jours**, **60 derniers jours**, **90 derniers jours** ou **Date personnalisée** (choisissez une **Date de début** et une **Date de fin**). Plage maximale : 90 jours.
4. Cliquez sur **Valider** pour afficher le relevé.
5. Cliquez sur **Télécharger le PDF**, ou saisissez votre **E-mail** puis cliquez sur **Envoyer le relevé**.

## Erreurs fréquentes
- « Plage maximale : 90 jours » : réduisez les dates.
- La date de fin doit être postérieure à la date de début.
- Menu ou onglet verrouillé : votre forfait ne l'inclut pas ; contactez votre agence.

## Parlez à un agent si
Il vous faut un relevé plus ancien que ce que propose le portail, ou un montant du relevé vous semble faux.
