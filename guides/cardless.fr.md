# Retrait sans carte

## Quand l'utiliser
Vous voulez retirer de l'argent sans carte, pour vous ou pour une autre personne, ou annuler une demande déjà faite.

## Étapes
1. Ouvrez **Retrait sans carte**. Trois onglets : **Moi-même**, **Une autre personne**, **Annuler la demande**. Un onglet verrouillé n'est pas inclus dans votre forfait.
2. **Moi-même** ou **Une autre personne** : choisissez le compte à débiter, vérifiez le numéro de **Téléphone** (c'est le vôtre, non modifiable pour « Moi-même » ; saisissez celui de la personne pour « Une autre personne »), et saisissez le **Montant**.
3. Le montant doit être un multiple de 5 000. Cette règle ne s'applique qu'au retrait sans carte.
4. Cliquez sur **Procéder**, puis saisissez votre code PIN (et le code OTP si votre profil l'exige).
5. Un code de retrait s'affiche. Copiez-le ou notez-le et gardez-le confidentiel : celui qui le détient peut retirer.
6. **Annuler la demande** : saisissez le code reçu, puis confirmez avec votre PIN. Une fois annulé, il ne peut plus être utilisé.

## Erreurs fréquentes
- « Le montant doit être un multiple de 5 000 ».
- « Fonds insuffisants ».
- Mauvais code PIN ou OTP.

## Parlez à un agent si
Vous avez perdu le code ou l'avez partagé par erreur, avez été débité sans recevoir l'argent, ou ne parvenez pas à annuler.
