# Generate or cancel a cash-out voucher code

## When to use
You want a voucher code that someone can redeem for cash, or you want to cancel a code you generated.

## Steps: generate
1. Open **Vouchers**, tab **Generate Cashout Voucher Code**.
2. Under "Information to Fill", choose the account to debit, enter the **Amount** and the **Motive** (at least 3 words).
3. Click **Proceed**, check the details, then enter your PIN (and the OTP if your profile requires it).
4. The voucher code is shown. **Copy the code now** and share it only with the person who should redeem it.

## Steps: cancel
1. Tab **Cancel Voucher Code**.
2. Enter the **Voucher Code** you generated, click **Proceed**, confirm with your PIN.
3. Once cancelled, the code can no longer be redeemed.

## Common errors
- "Insufficient funds".
- Code not found or already used: check it was typed correctly.
- Lost the code: the portal does not show it again. Talk to a human agent.

## Talk to a human if
You lost the code, a code was redeemed by someone you did not intend, or you were debited but got no code.
