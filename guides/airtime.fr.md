# Acheter du crédit téléphonique

## Quand l'utiliser
Vous voulez recharger un téléphone avec du crédit depuis votre compte.

## Étapes
1. Ouvrez l'entrée **Airtime** du menu (page « Value Added Services »), onglet **Crédit téléphonique**. (**Recharge groupée de crédit téléphonique** sert à recharger plusieurs numéros à la fois.) Si l'onglet est verrouillé, votre forfait ne l'inclut pas.
2. Choisissez le **pays**, puis l'**opérateur**. Si vous voyez « Aucun opérateur disponible », les opérateurs ne sont pas encore disponibles pour ce pays.
3. Dans le panneau de droite, choisissez le compte à débiter (« Sélectionner le compte à débiter »). Son solde s'affiche.
4. Saisissez le numéro de **Téléphone** à recharger et le **Montant**.
5. Cliquez sur **Procéder**. Une fenêtre « Confirmation de la transaction » s'affiche. Vérifiez les détails.
6. Saisissez votre code PIN et validez. Si votre profil l'exige, saisissez le code OTP qui vous est envoyé.
7. Attendez le résultat : **Paiement réussi**, **Paiement en attente** ou **Paiement échoué**.

## Erreurs fréquentes
- « Fonds insuffisants » : le montant dépasse le solde du compte choisi.
- Les champs restent désactivés tant que vous n'avez pas choisi un opérateur.
- « Mauvais code PIN » / « Mauvais code OTP » : ressaisissez avec soin ; ne les communiquez jamais.
- **Paiement en attente** : ne rachetez pas. Vérifiez d'abord dans **Historique**.

## Parlez à un agent si
Vous avez été débité mais le téléphone n'a pas été rechargé, ou le paiement reste en attente.
