# Se connecter, et que faire en cas de blocage

## Quand l'utiliser
Vous ne pouvez pas vous connecter, votre compte est bloqué, ou on vous demande de mettre à jour votre mot de passe ou votre PIN.

## Étapes : se connecter
1. Sur la page de connexion, saisissez votre **Identifiant de wallet** et votre **Mot de passe** (le champ s'appelle Mot de passe, pas PIN).
2. Complétez la **Vérification de sécurité** : saisissez le code affiché (utilisez **Actualiser le code** s'il est illisible).
3. Cliquez sur **Connexion**. Si votre profil l'exige, saisissez le code OTP qui vous est envoyé.
4. Vous arrivez sur **Overview**.

## Première connexion ou identifiants expirés
- Première connexion : le portail vous demande d'initialiser votre mot de passe, puis votre PIN.
- « Votre mot de passe a expiré. Veuillez le mettre à jour » ou « Votre code PIN a expiré. Veuillez le mettre à jour » : saisissez l'ancienne valeur, la nouvelle et sa confirmation. Un nouveau mot de passe doit contenir au moins une majuscule, une minuscule et un caractère spécial, de 8 à 15 caractères.
- « Les mots de passe ne correspondent pas » ou « Les codes PIN ne correspondent pas » : ressaisissez la confirmation.

## Messages et signification
- « Votre compte est inactif » : le compte n'est pas actif.
- « Nombre de tentatives de connexion dépassé : Votre compte a été désactivé » ou « plus de trois tentatives » : le compte a été désactivé après des échecs.
- « Veuillez patienter environ 2 minutes avant de réessayer » : attendez puis réessayez.
- « Vous n'êtes pas abonné à ce service » ou « Votre abonnement n'est pas encore actif » : l'abonnement n'est pas actif.
- « Votre compte est en attente de rattachement au niveau bancaire » / « Veuillez valider le rattachement de compte » : le rattachement du compte est en cours.
- « Le code ne correspond pas, réessayez » : le code de vérification de sécurité était faux.

## Parlez à un agent si
Votre compte est désactivé ou inactif, vous avez oublié votre mot de passe ou votre PIN (le portail n'a pas de réinitialisation en libre-service), ou l'abonnement ou le rattachement n'est pas actif. L'assistant ne peut rien réinitialiser et ne demande jamais votre mot de passe, PIN ou OTP.
