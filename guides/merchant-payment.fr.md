# Payer un marchand par code ou par QR code

## Quand l'utiliser
Vous voulez payer un commerce ou un service qui vous a donné un code marchand ou un QR code.

## Étapes : payer par code marchand
1. Ouvrez **Payments**, onglet **Paiement par code marchand**.
2. Choisissez le compte à débiter, saisissez le **Code marchand**, le **Montant** et le **Motif** (au moins 3 mots).
3. Cliquez sur **Procéder**, vérifiez la fenêtre de confirmation, puis saisissez votre code PIN (et le code OTP si votre profil l'exige).

## Étapes : payer par QR code
1. Onglet **Importer un QR Code**, téléversez l'image du QR code du marchand.
2. Vérifiez les détails affichés, puis saisissez votre code PIN (et le code OTP si nécessaire).
3. Si l'image n'est pas lisible, une erreur sur le téléversement du QR code s'affiche ; essayez une image plus nette.

## Erreurs fréquentes
- Mauvais code marchand : vérifiez-le auprès du marchand.
- « Fonds insuffisants ».
- **Paiement en attente** : ne payez pas à nouveau ; vérifiez dans **Historique**.

## Parlez à un agent si
Vous avez été débité mais le marchand n'a pas reçu le paiement, ou vous avez payé le mauvais marchand.
