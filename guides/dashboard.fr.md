# Overview : voir votre solde et vos dépenses

## Quand l'utiliser
Vous voulez voir le solde de votre compte, le solde disponible et les statistiques de dépenses.

## Étapes
1. Ouvrez **Overview** (vous y arrivez après la connexion).
2. Choisissez le compte (« Sélectionner un compte »). Le numéro et le nom du compte s'affichent.
3. Le solde est masqué. Cliquez sur l'icône œil, et saisissez votre PIN si demandé, pour afficher le **Solde comptable** et le **Montant disponible**. Le solde se masque de nouveau après environ 30 secondes.
4. Utilisez les boutons de période **Aujourd’hui**, **Hebdomadaire**, **Mensuel**, **Annuel** pour changer les statistiques affichées.

## Erreurs fréquentes
- Solde verrouillé ou message de mise à niveau : la consultation du solde n'est pas incluse dans votre forfait ; contactez votre agence.
- Mauvais PIN : ressaisissez-le. Ne saisissez jamais votre PIN dans le chat.

## Parlez à un agent si
Le solde vous semble faux, ou vous ne parvenez pas à l'afficher même avec le bon PIN.
