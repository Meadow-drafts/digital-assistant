# Envoyer de l'argent hors de la zone CEMAC (remittance sortante)

## Quand l'utiliser
Utilisez cette option pour envoyer de l'argent à une personne située dans un pays hors de la zone CEMAC. Le destinataire peut être identifié par compte, wallet, carte ou voucher, avec ses informations d'identité.

## Étapes
1. Ouvrez **Transfert**, onglet **Remittance sortante**.
2. Sous « Type d'envoi sortant », choisissez **Compte**, **Wallet**, **Carte** ou **Voucher**. Une carte verrouillée n'est pas incluse dans votre forfait.
3. Choisissez le compte à débiter.
4. Saisissez le **Numéro de compte**, l'**Identifiant du wallet** ou le **Numéro de carte** du destinataire (selon le type), puis le **Montant** et le **Motif** (au moins 3 mots).
5. Renseignez l'identité du destinataire sous « Informations sur le destinataire » : **Prénom**, **Deuxième prénom**, **Type de pièce d'identité** (Carte nationale d'identité, Passeport ou Carte de réfugié), **Numéro de pièce d'identité**, **Adresse**, **Ville**, **Pays**, **Téléphone**, **Date de naissance**.
6. Cliquez sur **Procéder**, vérifiez la fenêtre de confirmation, puis saisissez votre code PIN (et le code OTP si votre profil l'exige).

## Erreurs fréquentes
- Champ d'identité manquant : tous sont nécessaires.
- « Fonds insuffisants ».
- Mauvais code PIN ou OTP.

## Parlez à un agent si
Le destinataire ne peut pas retirer l'argent, ou vous avez saisi une mauvaise identité ou un mauvais numéro.
