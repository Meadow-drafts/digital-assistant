# Payer une facture

## Quand l'utiliser
Vous voulez payer une facture (eau, électricité, service) depuis votre compte.

## Étapes
1. Ouvrez **Payments**, puis **Bill payment** (« Effectuer un paiement de facture »).
2. Choisissez le **pays**, puis le **facturier**. Certains facturiers peuvent être verrouillés par votre forfait.
3. Dans le panneau de droite, choisissez le compte à débiter.
4. Sous « Sélectionner le type de facture », choisissez **Numéro de facture** ou **Numéro de contrat**, puis saisissez ce numéro.
5. Saisissez le **Montant** et le **Motif** si le formulaire les demande.
6. Cliquez sur **Procéder**. Le portail recherche la facture et affiche un tableau « Confirmation de la transaction » : référence, montant dû, date et statut.
7. Cochez la ou les factures à payer (seules les factures impayées sont cochables), puis cliquez sur **Valider**.
8. Saisissez votre code PIN. Si votre profil l'exige, saisissez le code OTP qui vous est envoyé.
9. Attendez le résultat : **Paiement réussi**, **Paiement en attente** ou **Paiement échoué**. Conservez la référence de la transaction.

## Erreurs fréquentes
- Aucune facture affichée : revérifiez le numéro de facture ou de contrat auprès de votre facturier.
- Rien n'est cochable : la facture est déjà payée.
- « Fonds insuffisants » : le montant dû dépasse le solde du compte.
- **Paiement en attente** : ne payez pas à nouveau. Vérifiez d'abord dans **Historique** ; payer deux fois peut vous débiter deux fois.

## Parlez à un agent si
Vous avez été débité mais le facturier indique « impayé », ou vous avez payé deux fois.
