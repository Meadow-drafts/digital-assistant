# Outils marchand : dépôt, retrait, générer un QR code, utiliser un voucher

## Quand l'utiliser
Vous êtes un client marchand et devez encaisser des paiements ou servir des clients.

## Étapes
- **Dépôt en espèces** (menu « Cash-in / Cash-out », onglet **Dépôt en espèces**) : choisissez le compte à débiter, saisissez le **Numéro de compte** ou l'**Identifiant du wallet** du bénéficiaire, le **Montant** et le **Motif**, puis **Procéder** et confirmez avec votre PIN.
- **Retrait en espèces** (onglet **Retrait en espèces**, visible seulement si votre profil marchand a un alias) : saisissez le **Wallet destinataire**, le **Montant**, le **Motif** et l'identité du destinataire (noms, type et numéro de pièce, adresse, ville, pays, téléphone, date de naissance), puis **Procéder** et confirmez avec votre PIN.
- **Générer un QR Code** (menu paiement marchand) : saisissez le **Montant** et le **Motif**, **Procéder**, confirmez avec votre PIN, puis **Télécharger le QR Code** pour l'afficher ou l'imprimer.
- **Utiliser un voucher** : saisissez le code voucher donné par le client et les informations demandées, puis confirmez avec votre PIN. Le code doit être valide et non utilisé.

## Erreurs fréquentes
- Onglet Retrait absent : votre profil n'a pas d'alias marchand.
- Code voucher invalide ou déjà utilisé.
- Onglet verrouillé : non inclus dans votre forfait.

## Parlez à un agent si
Un client a payé mais vous n'avez rien reçu, ou un voucher est refusé alors que le client affirme qu'il est valide.
