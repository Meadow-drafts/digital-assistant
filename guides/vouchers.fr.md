# Générer ou annuler un code voucher de retrait

## Quand l'utiliser
Vous voulez un code voucher qu'une personne peut échanger contre d'espèces, ou vous voulez annuler un code que vous avez généré.

## Étapes : générer
1. Ouvrez **Vouchers**, onglet **Générer un code voucher de retrait**.
2. Sous « Informations à renseigner », choisissez le compte à débiter, saisissez le **Montant** et le **Motif** (au moins 3 mots).
3. Cliquez sur **Procéder**, vérifiez les détails, puis saisissez votre code PIN (et le code OTP si votre profil l'exige).
4. Le code voucher s'affiche. **Copiez le code maintenant** et ne le communiquez qu'à la personne qui doit le retirer.

## Étapes : annuler
1. Onglet **Annuler le code voucher**.
2. Saisissez le **Code Voucher** que vous avez généré, cliquez sur **Procéder**, confirmez avec votre PIN.
3. Une fois annulé, le code ne peut plus être utilisé.

## Erreurs fréquentes
- « Fonds insuffisants ».
- Code introuvable ou déjà utilisé : vérifiez qu'il est bien saisi.
- Code perdu : le portail ne l'affiche plus. Parlez à un agent.

## Parlez à un agent si
Vous avez perdu le code, un code a été utilisé par une personne non prévue, ou vous avez été débité sans recevoir de code.
