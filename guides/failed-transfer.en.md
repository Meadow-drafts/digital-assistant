# My transaction failed: what the message means and what to do

## When to use
A transfer or payment ended with an error message or **Payment Failed**.

## What the message means
| Message | Meaning | What to do |
|---|---|---|
| Insufficient balance / Insufficient funds | The amount (plus fees) is above your available balance | Check your balance, lower the amount |
| Wrong PIN code / Wrong OTP code | The PIN or OTP you typed is not correct | Retype carefully. Never share them with anyone, including this chat |
| Amount limit exceeded; "below the minimum" / "exceeds the maximum" | The amount is outside the allowed range; the message shows the amount and the limit | Change the amount |
| Daily / weekly / monthly / quarterly / semester / annual limit reached | You reached the cumulative amount limit for that period | Wait for the next period or contact your branch |
| Maximum number of transactions reached (daily to annual) | You reached the allowed number of operations for that period | Wait for the next period or contact your branch |
| Maximum transactions exceeded | Amount or count limit reached (the portal uses one message for both) | Contact your branch to know which |
| Wallet not found / Destination wallet/Account not found | The receiver does not exist or is not valid | Check the number with the recipient |
| You cannot transfer to yourself | Sender and receiver wallet are the same | Choose another recipient |
| Account not found / Couldn't get credit account | An account is not configured or attachment is incomplete | Contact your branch |
| Client blocked / OPPOSITION | Your account is blocked or under opposition | Contact your branch |
| Account already attached or awaiting validation at head office | The account link is not yet complete | Wait for validation, or contact your branch |
| Gimac service unavailable | The GIMAC network is down for now | Try later; do not repeat in a loop |
| Application under maintenance / Transactions blocked, try later | The service is temporarily unavailable | Try again later |
| Invalid amount / The operation amount is zero | The amount is wrong | Enter a valid amount |
| Reversal is currently disabled | Reversals are turned off at the bank | Contact your branch |
| Operation failed / An exception occurred while processing | A technical problem | Check **History** to see whether you were debited, then contact an agent |

## Important
- If the status is **Payment Pending**, do not retry. Check **History** first.
- If you were debited but the transaction failed, talk to a human agent with the transaction reference.

## Talk to a human if
You were debited and the transaction failed, the message is not in this list, or you need a reversal.
