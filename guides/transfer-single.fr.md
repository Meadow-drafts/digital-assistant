# Effectuer un transfert unique

## Quand l'utiliser
Vous voulez envoyer de l'argent une fois, vers un compte ou un wallet, en local ou via GIMAC.

## Étapes
1. Ouvrez **Transfert** dans le menu, puis l'onglet **Transfert unique**.
2. Choisissez la destination : le réseau de la banque (par défaut) ou **GIMAC**. Pour GIMAC, choisissez aussi le pays et l'opérateur.
3. Sous « Type de transfert individuel », choisissez **Compte** ou **Wallet**. Si une carte est verrouillée, votre forfait ne l'inclut pas.
4. Dans « Informations sur le transfert » :
   - **Compte** : choisissez **Moi-même** (puis l'un de vos comptes) ou **Une autre personne** (puis saisissez le numéro de compte, en **IBAN** ou **Simple**).
   - **Wallet** : saisissez le **Wallet destinataire**. Vous ne pouvez pas envoyer à votre propre wallet.
5. Saisissez le **Montant** et le **Motif** (au moins 3 mots).
6. Cliquez sur **Procéder au transfert**. La fenêtre « Confirmation de la transaction » affiche le destinataire, le montant et les frais. Vérifiez-les attentivement.
7. Saisissez votre code PIN puis cliquez sur **Valider**. Si votre profil l'exige, vous devrez ensuite saisir le code OTP qui vous est envoyé.
8. Attendez le résultat : **Paiement réussi**, **Paiement en attente** ou **Paiement échoué**.

## Erreurs fréquentes
- « Fonds insuffisants » : le montant dépasse votre solde.
- « Mauvais code PIN » ou « Mauvais code OTP » : ressaisissez avec soin ; ne les communiquez à personne.
- « Le wallet/compte destinataire est introuvable » : vérifiez le numéro avec le destinataire.
- Messages de plafond (jour, semaine, mois) : vous avez atteint une limite ; le message indique le montant et le maximum.
- **Paiement en attente** : ne renvoyez pas l'argent. Ouvrez **Historique** et vérifiez d'abord le statut.

## Parlez à un agent si
Vous avez envoyé de l'argent à la mauvaise personne, un paiement reste en attente, ou vous avez été débité mais le transfert apparaît échoué.
