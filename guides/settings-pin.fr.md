# Modifier votre code PIN

## Quand l'utiliser
Vous voulez un nouveau code PIN de transaction et vous connaissez l'actuel. Si vous l'avez oublié, voir « Parlez à un agent ».

## Étapes
1. Ouvrez **Paramètres**, puis l'onglet **Modifier le code PIN**.
2. Saisissez votre **Code PIN actuel**.
3. Saisissez votre **Nouveau code PIN**. Sa longueur doit correspondre à celle définie pour votre profil.
4. Sous « Confirmer votre nouveau code PIN », saisissez-le à nouveau.
5. Cliquez sur **Procéder**. Vous devriez voir « Code PIN mis à jour avec succès ».

## Erreurs fréquentes
- « Les codes PIN ne correspondent pas » : ressaisissez le nouveau code et sa confirmation.
- Code actuel erroné : ressaisissez-le. Plusieurs erreurs peuvent bloquer votre accès.
- L'assistant ne demande jamais votre PIN ou OTP et vous ne devez jamais les saisir dans le chat.

## Parlez à un agent si
Vous avez oublié votre PIN, votre PIN a expiré et vous ne pouvez plus vous connecter, ou votre accès est bloqué.
