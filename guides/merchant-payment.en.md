# Pay a merchant by code or by QR code

## When to use
You want to pay a shop or service that gave you a merchant code or a QR code.

## Steps: pay by merchant code
1. Open **Payments**, tab **Payment By Merchant Code**.
2. Choose the account to debit, enter the **Merchant Code**, the **Amount** and the **Motive** (at least 3 words).
3. Click **Proceed**, check the confirmation window, then enter your PIN (and the OTP if your profile requires it).

## Steps: pay by QR code
1. Tab **Import QRCode**, upload the merchant's QR code image.
2. Review the details shown, then enter your PIN (and the OTP if required).
3. If the image is not readable you see an error about the QR code upload; try a clearer image.

## Common errors
- Wrong merchant code: check it with the merchant.
- "Insufficient funds".
- **Payment Pending**: do not pay again; check **History**.

## Talk to a human if
You were debited but the merchant did not receive the payment, or you paid the wrong merchant.
