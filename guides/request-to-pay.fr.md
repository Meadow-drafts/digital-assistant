# Demander de l'argent, et confirmer une demande reçue

## Quand l'utiliser
Vous voulez qu'une personne vous paie (Demande de paiement), ou vous avez reçu une demande et voulez la payer.

## Étapes : envoyer une demande
1. Ouvrez **Demande de paiement**, onglet **Nouvelle demande**.
2. Choisissez le **pays**, puis l'**opérateur**.
3. Dans « Informations sur la demande », saisissez le **Wallet destinataire** (la personne à qui vous demandez), le **Montant** et le **Motif** (au moins 3 mots).
4. Cliquez sur **Envoyer la demande**, vérifiez la fenêtre « Confirmation de la transaction », saisissez votre code PIN (et le code OTP si votre profil l'exige).
5. Vous devriez voir « Votre demande de paiement a été envoyée avec succès ».

## Étapes : suivre ou annuler une demande envoyée
- Onglet **Demande en attente** : vos demandes ouvertes, avec identifiant, wallets, date, montant et statut. Cliquez sur **Annuler** sur une ligne et confirmez pour la retirer.
- Onglet **Historique des demandes** : toutes les demandes passées.

## Étapes : payer une demande reçue
1. Ouvrez **Payments**, onglet **Confirmer la demande de paiement**.
2. Trouvez la demande (identifiant, wallet de l'expéditeur, montant, date, statut) et ouvrez-la.
3. Vérifiez le montant et le destinataire, puis saisissez votre code PIN pour confirmer la demande de paiement.

## Erreurs fréquentes
- « Wallet introuvable » : vérifiez le wallet destinataire.
- Le bouton d'envoi reste désactivé tant que l'opérateur, le wallet, le montant et le motif ne sont pas renseignés.
- Onglets verrouillés : votre forfait n'inclut pas la Demande de paiement ; contactez votre agence.

## Parlez à un agent si
Vous avez payé une demande que vous ne reconnaissez pas, ou vous avez été débité deux fois pour la même demande.
